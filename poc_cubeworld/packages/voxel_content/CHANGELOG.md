# Changelog

## 0.0.0

First version, not published.

- `BlockRegistry` / `BlockType`: blocks by string id, tags, drops, path costs; projects the engine's block table.
- `ItemRegistry` / `ItemType`: items, tools, tiers, stack sizes, durability.
- `MiningRules`: break times by tool and tier.
- `Inventory` / `ItemStack`: stacking, wear, listeners, JSON.
- `RecipeBook` / `Recipe`: all-or-nothing crafting by station.
- `LootTable`: seeded loot rolls.
- `StatusEffects`: timed effects with damage, healing and stat modifiers.
