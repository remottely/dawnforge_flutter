# 🎮 Game Controls (Stardew Valley Style)

## Movement
| Action | Keyboard |
|--------|----------|
| Move | **WASD** or **Arrow Keys** |
| Run | **Shift** (hold) |

## Core Actions
| Action | Keyboard | Description |
|--------|----------|-------------|
| Use Tool/Weapon | **Space** | Use the currently equipped tool or weapon |
| Interact | **X** | Check, pickup items, talk to NPCs |
| Secondary Action | **Z** | Alternative action (context-dependent) |

## Toolbar/Inventory
| Action | Keyboard | Description |
|--------|----------|-------------|
| Open Inventory | **Tab** | Toggle inventory screen |
| Next Tool | **E** | Cycle to next toolbar slot |
| Previous Tool | **Q** | Cycle to previous toolbar slot |
| Select Slot 1 | **1** | Select toolbar slot 1 directly |
| Select Slot 2 | **2** | Select toolbar slot 2 directly |
| Select Slot 3 | **3** | Select toolbar slot 3 directly |
| Select Slot 4 | **4** | Select toolbar slot 4 directly |
| Select Slot 5 | **5** | Select toolbar slot 5 directly |
| Select Slot 6 | **6** | Select toolbar slot 6 directly |
| Select Slot 7 | **7** | Select toolbar slot 7 directly |
| Select Slot 8 | **8** | Select toolbar slot 8 directly |
| Select Slot 9 | **9** | Select toolbar slot 9 directly |
| Select Slot 10 | **0** | Select toolbar slot 10 directly |
| Unequip Hand | **U** | Remove item from main hand |

## Menus
| Action | Keyboard | Description |
|--------|----------|-------------|
| Crafting Menu | **C** | Open crafting menu (not yet implemented) |
| Pause/Menu | **Esc** | Toggle pause menu |

## Debug/Testing
| Action | Keyboard | Description |
|--------|----------|-------------|
| Advance Day | **N** | Skip to next day (debug) |
| Add Test Items | **T** | Add test items to inventory (debug) |
| Clear Save | **G** | Delete save data (debug) |

## 🎯 Key Improvements (Aligned with Stardew Valley)

### ✅ Number Keys for Quick Selection
Just like in Stardew Valley, you can now press **1-9** and **0** to instantly select toolbar slots without cycling through them.

### ✅ Tab for Inventory
Changed from **I** to **Tab** to match Stardew Valley's default control.

### ✅ E/Q for Toolbar Cycling
- **E**: Next slot (like Stardew Valley)
- **Q**: Previous slot (like Stardew Valley)

### ✅ Better Organization
Controls are now organized by category (Movement, Actions, Inventory, Menus) for easier reference.

### 🔜 Future Additions
- **C**: Crafting menu (planned)
- **Mouse Click**: Direct tool usage (planned)
- **Right Click**: Alternative interaction (planned)
- **M**: Map view (planned)

---

## 📝 Notes

- All number keys (**1-0**) work for direct slot selection, matching Stardew Valley's intuitive toolbar system
- **Shift** must be held down to run (not a toggle)
- Debug keys (**N, T, G**) should be disabled in production builds
- The game automatically equips the first valid tool when starting
